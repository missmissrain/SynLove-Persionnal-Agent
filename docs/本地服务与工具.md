# 语音、模型与音乐服务

这些服务可独立运行，主程序通过 HTTP 接口连接。使用云端模型聊天时，不需要先安装本地模型或语音服务。

| 服务 | 安装与启动 | 环境要求 |
| --- | --- | --- |
| ASR 语音转写 | `python service.py asr` | Python 3.9+，首次转写下载 Whisper 模型 |
| TTS 语音合成 | `python service.py tts --python <Python3.12路径> --download-model` | Python 3.12+、Git，Breeze-TTS-2 权重 |
| 本地 LLM | `python service.py llm --download-model` | Windows 首次安装下载 llama.cpp CPU 引擎及模型 |
| 酷狗音乐 API | `python service.py kugou` | Node.js、Git；本机播放另需 FFmpeg |

加 `--plan` 查看安装计划，加 `--install-only` 只安装不运行。TTS 和 LLM 只有显式添加 `--download-model` 才主动下载权重。各服务使用 `.serviceEnvs/` 隔离环境，不依赖开发者机器上的其他工程。

## 连接主程序

在 `config/serviceConfig.json` 中配置 ASR、TTS 和 LLM 的地址：

- `external`：连接已运行的本机或远程服务，是发行版默认设置。
- `managed`：由主程序按需启动本地服务，需要先安装对应依赖与权重。

本地托管的启动命令、工作目录与健康检查也在服务配置中。更换部署机器时调整服务地址和对应的本地路径。

## 使用工具

启动服务后，可以用 `python tools/speak.py "要说的话"` 合成语音，用 `python tools/transcribe.py "音频路径" --language zh` 转写。语音发送需要配置相应的消息通道。

视频下载入口为 `tools/downloadVideo.py`，需要另外安装 yt-dlp 和 FFmpeg。

## 独立部署

配套仓库提供相同的安装入口，可部署在另一台机器：

- [synlove-asr](https://github.com/missmissrain/synlove-asr)
- [synlove-tts](https://github.com/missmissrain/synlove-tts)
- [synlove-gemma](https://github.com/missmissrain/synlove-gemma)
- [synlove-kugou](https://github.com/missmissrain/synlove-kugou)

服务默认监听本机。远程部署时需配置监听地址、网络访问控制和认证。
