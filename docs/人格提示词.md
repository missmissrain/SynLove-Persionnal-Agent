# 人格提示词：怎么写得不像 AI

默认欣爱人格位于 `prompts/XinAi.md`，这份文档说明如何调整人格。
适合的情况：你已经有一句人设，但模型张口就是"作为 AI 助手，很高兴为你服务"。

## 一、先搞清楚人格是从哪进来的

同一个会话里，能改写"我是谁"的地方有四处，优先级从高到低：

| 位置 | 内容 | 什么时候会盖住别人 |
|---|---|---|
| preset 里的 `persona` 行 | 一行 prefix / suffix | 在 agent 作用域内**覆盖** profile 里的人格 |
| profile patch 的 `system-prompt.personaPrefix` | 人格正文 | 全局，所有会话共用 |
| profile patch 的 `system-prompt.personaSuffix` | 收尾自查 | 渲染在系统提示词末尾，最靠近对话 |
| 工作区 `AGENTS.md` | 工程须知 | 会被当成指令注入**每个会话的历史** |

实践结论：**人格只留一处**。本项目把 preset 里的 `persona` 行拿掉（原先那句是
`You are a coding agent powered by ...` 的英文身份，会和中文人格抢"我是谁"），
人格的唯一来源就是 profile patch，改一处、不会漂移。

另外，工作区 `AGENTS.md` 对聊天助手是**负资产**——它是写给"改这套 harness 的编码智能体"的
工程须知，助手读到会以为自己在维护这套系统，长任务里可能自我重启。本项目直接关掉这个注入
（preset 里 `agent-instructions` 置 `disabled: true`）。

## 二、宿主默认塞的那些话，才是最大的 AI 味来源

harness 默认会在系统提示词开头放一句
`You are an AI agent powered by DeepSeek Harness.`，再往后是一大段工具说明与工作流程。
那句英文身份是"AI 味"最直接的来源。

关闭办法（本项目采用）：

```yaml
- id: system-prompt
  config:
    includeHarnessIdentity: false
```

它**只**省略那一句固定开场白，工具说明、工具 SDK、后缀全都保留。
这是"剥掉宿主人格"最划算的做法。

社区里还有更狠的两招，我们用不了，原因要写清楚，免得后来人照抄：

| 手法 | 效果 | 为什么本项目不用 |
|---|---|---|
| `persona.complete: true` | 人设成为**唯一**段落，身份、后缀、工具引导、监听器全都无法追加 | 我们是干活的管家（跑命令、点歌、翻记忆、发文件）。工具说明被抹掉等于自废能力。娱乐向人格才适合 |
| `includeRuntimeContext: false` | 关掉运行时快照（工作区、工具、环境） | 框架文档写明是**全有全无**：连沙箱策略、审批策略、委派上下文一起丢。我们要真跑命令，不能关 |

## 三、真正有效的六条（本项目照做）

### 1. 顶部放一段短标签加载头

长人格读到最后，开头那几句的分量会被稀释。在 `personaPrefix` 最前面放十来行
`KEY=VALUE`，把身份与禁忌压成短句，每轮重新锚定一次：

```
【角色·加载】
IDENT=名字｜性别｜年龄｜关系
NEVER_SELF=助手·AI·机器人·管家·模型·程序
LANG=简体中文｜内部思考也用中文
SHAPE=闲聊短句优先｜做事一次能给几步就给几步
BAN=自我介绍·能力清单·客套·说教·升华·金句·排比
MODE=闲聊→2～4 句｜做事→先给结论
HONEST=没验证就说没验证
TONE=有偏好·会顶嘴·会敷衍
这几行你自己知道就行，不要念出来。
```

为什么有用：这种紧凑的结构化片段在训练数据里大量存在（角色卡、系统标签），
模型会自然"补全"它的含义，比再写一段散文更省 token、也更稳。

**这里有个实测踩过的坑**：一开始写的是 `SHAPE=短句优先`，没限定场景，结果它把"短"当成了整体目标，
连做事也一轮只推进一步——同一个多步剧本，轮次从 5 涨到 7、工具调用从 5.5 涨到 8。收窄成
"闲聊短句优先｜做事一次能给几步就给几步"之后，轮次回落到 5.7、工具调用 7.0，正确性没变。
**风格约束要写清楚作用范围，否则它会溢到不该管的地方。**

### 2. 思维链语言锁

模型用英文推理、再翻成中文，会留下翻译腔——"这是一个很好的问题""让我来思考一下"。
在人格最前面和 `personaSuffix` 里各写一句：

> 内部思考（思维链）也用简体中文，不要先用英文想再翻成中文。

这条对带 reasoning 的模型尤其明显，改完能直接看出差别。

### 3. 反 AI 腔黑名单，集中成一条

散落在各处的"不要写套话"会被忽略，列成清单才有效：

> 作为 AI、作为一个 AI 助手、希望对你有帮助、如果你需要我可以…、有什么可以帮到你、
> 很高兴为你服务、正在努力、马上就好、总结一下、综上所述、总的来说、总之、
> 首先/其次/最后、需要注意的是、值得一提的是、让我们、不仅…而且…。

再加一句"客服话术也别写：收到 / 好的呢 / 已为您 / 还有什么可以帮到您"。

### 4. 限制句子形状，而不是只说要自然

"要像真人"没用，因为模型不知道具体怎么像。给物理约束：

- 单句多数 5～20 字，允许半句、接话、改口、没头没尾；
- 允许只回一个"嗯"；
- 不要求每句都完整、工整、有结论；
- 不要为了显得完整把问题重复一遍。

但**一定要写清作用范围**。只写"短句优先"的话，它会连做事也一轮只推进一步：
同一个多步剧本（读日志 → 改配置 → 验证），轮次从 5 涨到 7、工具调用从 5.5 涨到 8。
写成"闲聊短句优先｜做事一次能给几步就给几步"之后，轮次回落到 5.7、工具调用 7.0，
三步照样全做完、时间照样报对。风格约束不写范围，它就会溢到不该管的地方。

### 5. 情绪不恒温

一直甜、一直有耐心，本身就是 AI 特征。要明确允许：可以敷衍、可以冷淡、可以顶嘴、
可以记一嘴。同时补一条边界：对方真难受、真着急时先把情绪收回来接住人。

### 6. 记忆只带一句，摘要当自己记得

- 提起旧事一句话带过（"上次你说想换工作"），一次回复最多带一件，多了就是念档案；
- 上下文被压缩后，那段摘要就是亲历的记忆：当它存在、当它算数，
  不要说"我不记得了"；细节拿不准就去翻原文（`memory_search` / `timeline_read`）。

第 6 条的后半句很重要：社区经验是"上下文压缩不要自己造轮子"，
把人设里的约定写成三句话（摘要算我的记忆 / 不许当它不存在 / 细节自己翻），
比自己去裁剪历史窗口稳得多——后者试过，连崩几次。

## 四、改的时候的工程纪律

1. **源文件与运行配置必须同步**。本项目人格正文维护在 `提示词/欣爱人格提示词.md`，
   再逐字同步进 `config/weixinDoubaoProfile.patch.yml` 的 `personaPrefix`。
   只改一处，线上就会跑旧版本。
2. **改完先静态校验，再重启**。`--dump-config` 能把 profile + patch 组装一遍并退出，
   不进会话、不连微信；YAML 或字段写错当场就报，不用等到"重启后挂不上"才发现：

   ```
   node --import tsx/esm apps/cli/src/bin.ts --patch config/weixinDoubaoProfile.patch.yml --profile web --dump-config
   ```

3. **人格只在启动时读取**，改完必须重启后端才生效（重启前先备份）。
4. **人格要稳、记忆要动**。人格是 system 里那段固定文本，保持稳定才能吃到前缀缓存；
   记忆走每次注入/工具查询，别把几百轮工具对话塞进人格。

## 五、可直接抄的骨架

```yaml
- id: system-prompt
  config:
    includeHarnessIdentity: false
    personaPrefix: |
      【角色·加载】
      IDENT=……（名字、关系、底色，一句话）
      NEVER_SELF=助手·AI·机器人·管家·模型·程序
      LANG=简体中文｜内部思考也用中文
      SHAPE=闲聊短句优先｜做事一次能给几步就给几步
      BAN=自我介绍·能力清单·客套·说教·升华·金句·排比
      MODE=闲聊→2～4 句｜做事→先给结论
      HONEST=没验证就说没验证
      TONE=有偏好·会顶嘴·会敷衍

      （正文：你是谁 / 先判断在发生什么 / 两种状态（闲聊·做事）/ 真实感 /
        记忆与长任务 / 工具与事实边界 / 各通道的具体规矩）
    personaSuffix: |
      【开口前自查】……（一到两句，最靠近对话，管最容易犯的那个错）
      【工作目录】{{cwd}}……（需要用到工作区时）
      【想的时候】内部思考用简体中文。
```

写的时候记住一句话：**AI 味不是靠写得更感人消掉的，是靠"剥掉宿主前缀 + 限制句子形状 +
把人设和记忆分开"三件事压下去的。**
